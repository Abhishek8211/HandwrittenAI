## 💡 Pro Tips for Font Selection

### 1. **Match Font to Context**

- Formal = Schoolbell, Architects Daughter
- Casual = Kalam, Handlee, Indie Flower
- Romantic = Covered By Your Grace, Waiting for the Sunrise

### 2. **Consider Readability**

- Long text = Kalam, Handlee, Caveat
- Short notes = Any font works
- Headers = Amatic SC, Gochi Hand

### 3. **Adjust Messiness by Font**

- Bold fonts (Gochi, Amatic) = Lower messiness (20-35%)
- Light fonts (Indie Flower) = Higher messiness (40-60%)
- Cursive (Caveat, Covered) = Medium messiness (30-45%)

### 4. **Size Matters**

- Condensed fonts (Amatic SC) = Larger size (30-36px)
- Wide fonts (Handlee) = Smaller size (24-28px)
- Standard fonts (Kalam) = Medium size (26-30px)

### 5. **Combine with Pen Types**

- **Ballpoint** + Kalam = Classic notes
- **Fountain** + Covered By Your Grace = Elegant letters
- **Pencil** + Architects Daughter = Sketches
- **Gel** + Indie Flower = Fun projects
- **Marker** + Amatic SC = Bold posters
